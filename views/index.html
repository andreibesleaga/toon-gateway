JSON APIs in. TOON out. Fewer tokens for your LLM.

TOON Gateway sits in front of any JSON API and returns the same data as TOON (Token-Oriented Object Notation), a compact, human-readable encoding of the JSON data model built for LLM prompts. No client changes: point your agent at the gateway instead of the API. Responses are cached in Redis.

Response headers

HeaderMeaning
Content-Type: text/toonThe body was converted. Any other type means the upstream did not return JSON and the body is untouched.
X-Cache: HITServed from Redis without contacting the upstream.
X-Cache: MISSFetched from the upstream, converted, then cached.
X-Cache: BYPASSThe request carried Authorization, Cookie or X-API-Key, so it was neither read from nor written to the shared cache.
X-Cache: UNAVAILABLERedis is down; the request was served uncached.
RateLimit-*Remaining request budget and reset time for your IP.

How it works

A transparent layer between your client and an API you already use. It never changes the request, only the shape of a JSON response.

RequestYour client or agent calls the gateway with the API's own path and query.
CacheFor GETs, Redis is checked first. A hit returns TOON immediately.
UpstreamOn a miss the request is forwarded to the configured API.
TransformJSON is encoded with the official @toon-format/toon library, cached and returned.

Why TOON

JSON repeats every key on every row and spends tokens on braces and quotes. TOON states the field names once, like a CSV header, then lists the rows, and keeps an explicit length so a model can check it read everything. Uniform arrays of objects, the usual shape of API results, shrink the most, including rows with nested objects, which TOON v4 flattens into grouped columns such as geo{lat,lng}; irregular data shrinks less. It is lossless: TOON decodes back to the same JSON. See the specification and toonformat.dev.

Run your own

This public instance points at a demo API. To put the gateway in front of your own API, run it yourself and set UPSTREAM_URL.

git clone {{REPO_URL}}.git
cd toon-gateway
docker-compose up -d            # gateway on :3000 + Redis
curl http://localhost:3000/posts/1
